## Telepítés

1. Töltsd le a telepítőt, és futtasd.
2. A telepítő nem kér rendszergazdai jogot, a program a te felhasználói fiókodba települ.
3. Első indításkor a Pointlark végigvezet a beállításon.

### „A Windows megvédte a számítógépedet" figyelmeztetés

A telepítő még nincs digitálisan aláírva, ezért a Windows SmartScreen figyelmeztethet. A továbblépéshez kattints a **További információ**, majd a **Futtatás mindenképpen** gombra. Az ellenőrzéshez a kiadás leírásában megtalálod a fájl SHA-256 ellenőrző összegét (PowerShellben: `Get-FileHash .\Pointlark-telepito.exe`).

The installer does not need administrator rights. It is not code-signed yet, so Windows SmartScreen may warn you: click **More info**, then **Run anyway**. The SHA-256 checksum is in the release notes (PowerShell: `Get-FileHash .\Pointlark-telepito.exe`).
